자주 묻는 질문

규제 적법성 및 서비스 운영 방식에 대해 명확한 팩트를 안내드립니다.

행정사법 위반 소지는 없나요? +
유사 셀프서브 플랫폼의 불기소 사례와 책임분리 원칙을 참고하며, 법률 검토를 진행 중입니다. Formu는 사용자가 직접 입력한 데이터를 바탕으로 표준 서식을 정리하는 순수 셀프서브 소프트웨어(SaaS)를 지향합니다. 개별 법적 대리나 유권해석이 필요한 복잡 건은 제휴된 공인 행정사에게 적법하게 연결합니다.
공인시험기관(KTR, KCL 등)과의 협력 원칙은 무엇인가요? +
공익기관 회계규정에 따라 Formu는 공인시험기관으로부터 일체의 중개 수수료를 수취하지 않습니다. 창작자가 시험 성적서를 편리하게 발급받을 수 있도록 시료 접수 안내 및 전자 성적서 API 연동 파트너로만 투명하게 협력합니다.
브랜드의 핵심 배합 레시피는 안전하게 보호되나요? +
현재 배합 데이터 보호 정책 설계 중이며, 서식 다운로드 완료 후 서버에 원본 배합표가 영구 저장되지 않도록 안전하게 처리할 예정입니다. 고객의 배합 기밀은 제3자에게 절대 공유되지 않습니다.
