01 · PROBLEM

소수점 하나 틀려 단상자 3,000장 전량 폐기하기 전에.

1인 브랜드는 제품 개발보다 분산된 6~7곳의 규제 행정 접점에서 먼저 좌절합니다.

PAIN 01
분산된 6~7개 행정 접점
시험기관 시료 접수 ➔ 성분·배합 정리 ➔ 환경부 CHEMP 신고 ➔ 식약처 라벨 문구 ➔ 인쇄소 감수 등 1인 사업자가 어디서부터 손대야 할지 막막함.
➔ 제품 1개당 평균 2개월 소요
PAIN 02
막대한 라벨·단상자 폐기 손실
알레르기 유발성분 26종 표기를 누락하거나 배합비 소수점 하나만 잘못 적어도 표시 위반 판정. 이미 인쇄된 단상자 3,000장 전량 폐기 및 과태료 위험.
➔ 건당 300만~500만 원 매몰 비용
PAIN 03
부처별 규제 이원화 이중고
디퓨저·캔들은 환경부(생활화학제품), 향수·미스트는 식약처(화장품법)로 관할 분리. 같은 향을 다루면서도 두 법률의 개정 고시를 매번 추적해야 함.
➔ 1인 사업자의 법령 추적 한계
* 근거: 화장품·생활화학제품 표시·광고 위반 실태조사, 디퓨저 출시 소요기간 2개월 (출처: attorney0070)

02 · SOLUTION

배합표 한 장 업로드 → 신고 서식·라벨 문구 자동 정리

서류를 남에게 맡기는 외주가 아닌, 사용자가 직접 손쉽게 신고하도록 돕는 셀프서브(Self-Serve) SaaS

BEFORE · 기존의 복잡한 6~7곳 접점
1. 원료별 CAS 번호 및 관할 부처 수기 검색 (오류 빈번)
2. 화학물질관리시스템(CHEMP) 100% 배합비 엑셀 수기 연산
3. 식약처 26종 알레르기 유발성분 함량 수동 필터링
4. 행정사 건별 서류 의뢰 시 건당 15~30만 원 부담
5. 표시기재 문구 오기재로 단상자 인쇄 후 전량 폐기 위험
AFTER (FORMU) · 배합표 입력 1곳으로 단축
✔ 공공 원료 DB 자동 매핑
원료명 입력 시 식약처 2.1만 DB 기반 성분 코드·알레르기 후보 즉시 제시
✔ 법정 신고 서식 자동 완성
환경부 CHEMP 100% 배합비율표 엑셀 양식 단 1초 만에 자동 완성
✔ 라벨 표시기재 체크리스트
2024 개정 26종 알레르기 성분 함량 계산 및 패키지 필수 문구 도출
✔ 안전한 셀프서브 아키텍처
사용자가 직접 확인·신고하여 법적 책임 완벽 분리 (불필요한 외주 수수료 0원)

04 · DIFFERENTIATION

1인 브랜드 출시 과정에 최적화된 4가지 핵심 차별화

서류를 대신 맡아주는 고비용 외주가 아니라, 사용자가 직접 손쉽게 검토·신고하는 혁신 구조

01
셀프서브 소프트웨어 구조
서류를 남에게 맡기는 외주 방식이 아니라, 사용자가 직접 손쉽게 신고하도록 서식을 자동 정리하는 SaaS. 복잡한 건만 제휴 행정사 연결.
02
공공 원료 DB 자동 매핑
식약처 공개 화장품 원료 성분 정보(약 2.1만 건 API) 기반으로 원료명 검색 시 성분 코드·알레르기 유발성분 후보 자동 제시.
03
파생제품 중복시험 점검
대표제품과 조건이 맞는 파생제품인지 사전 점검하여 불필요한 반복 시험을 줄일 가능성 안내 (환경부 KEITI 매뉴얼 준용).
04
1인 브랜드 맞춤형 원스톱
대기업 대상 무거운 엔터프라이즈 ERP가 아닌, 1인 향수·디퓨저 공방의 빠른 소량 다품종 출시에 최적화된 워크플로 제공.
* 책임 분리: 원료 매핑 결과는 공공 DB 기반 후보 제시이며 최종 확인은 사용자 책임 원칙 (유사 세무 플랫폼 적법 판례 준용)

1단계 · 초기 (현재~8주)
건당 유료 '규제 서식 정리 리포트'
3만 원대 / 건당 (Take Rate 100%)
배합표 ➔ 환경부 CHEMP 신고 서류 초안 + 식약처 26종 라벨 문구 체크리스트 제공. 저가 진입으로 첫 유료 고객 유치.
2단계 · 반복 증가 (8주~6개월)
셀프서브 SaaS 정기 구독
월 3~5만 원 / 월 (Take Rate 100%)
원료 DB 자동 매핑, 신규 개정 고시 실시간 업데이트, 다수 제품 배합표 보관 및 버전 관리 셀프서브 소프트웨어.
3단계 · 파트너 연결 (6개월~)
라벨·단상자 인쇄 파트너 연결
파트너 결제액의 10~15% 수수료
규제 검증이 끝난 정확한 표시기재 문구로 라벨·단상자 인쇄 파트너 연계. 인쇄 사고 방지 및 파트너 중개 수수료 수취.

10 · THE VISION

배합표 한 장을 출시 가능한 제품으로

창작자가 서류 때문에 멈추지 않고, 오직 향과 제품의 본질에만 몰입하는 세상

“창작은 당신이, 규제는 포뮤(Formu)가.”
소수점 하나 때문에 수천 장의 단상자를 폐기하던 막막함을 끝내고,
배합표 입력만으로 법적 신고 서식 완성부터 인쇄 파트너까지 원스톱으로 연결합니다.
VALUE 01
폐기 리스크 감소
소수점 오타와 알레르기 성분 누락을 사전 점검하여 수천 장의 단상자 폐기 및 표시 위반 과태료 방지
VALUE 02
출시 시간 90% 단축
2개월 걸리던 6~7곳의 분산된 규제 행정을 단 1초의 배합표 데이터 정리로 압축
VALUE 03
원스톱 출시 파트너
배합표 입력 하나로 환경부 CHEMP 서식 완성, 시험기관 시료 접수, 라벨 인쇄까지 원스톱 연계
* Formu (포뮤) — 모두의 창업 2기 예비창업자 발표를 마칩니다. 경청해 주셔서 감사합니다.
